SimGolf needs a mouse and a big screen, so it doesn't work on phones or tablets. Open this page on a desktop or laptop.
This browser can't run the game yet. Use a recent Chrome or Edge (version 137 or newer) on a desktop or laptop.
  1. Download the game disc from the Internet Archive (the .7z file, about 250 MB). An .iso of the disc from elsewhere works too.
  2. Get the v1.02 no-CD golf.exe, usually a zip called SIMGOLF.102.ENG.MYTH.NOCD.ZIP, from Abandonware DOS.
  3. Choose both files below, just as they downloaded; no need to unzip anything. The page unpacks the game in about a minute and keeps it in this browser, so you only do this once.
