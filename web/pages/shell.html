Sid Meier's SimGolf

The 2002 game, running in your browser. You bring the game files; nothing is uploaded anywhere.

This browser can't run the game yet. Use a recent Chrome or Edge (version 137 or newer) on a desktop or laptop.
  1. Download the game. You need the SimGolf CD image (.iso) and the v1.02 no-CD golf.exe. The download on MyAbandonware or other abandonware sites usually comes as one zip with both inside.
  2. Choose that zip below, or the .iso and the no-CD golf.exe (or its own zip) together.
  3. Wait about a minute while the page unpacks the game. It's saved in this browser, so you only do this once.

The game's intro and closing videos aren't played in this version. Saves stay in this browser; use Ctrl+F8 in the game to download or import them. To start over with different files, open this page with ?reset on the end of the address.
